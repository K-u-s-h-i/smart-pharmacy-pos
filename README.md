# Smart Pharmacy POS & Inventory Management System

## Overview
A web-based application developed to manage pharmacy billing,
medicine inventory, expiry tracking, and sales records.

## Problem Statement
Manual pharmacy management often leads to billing errors,
expired medicine sales, and poor stock visibility.
This system helps streamline daily pharmacy operations.

## Features
- Medicine inventory management
- Billing and sales records
- Stock and expiry date tracking
- CRUD operations on medicine data
- Basic reporting for inventory and sales

## Tech Stack
- Frontend: React
- Backend: Node.js
- Database: MySQL / MongoDB
- Tools: Git, GitHub
