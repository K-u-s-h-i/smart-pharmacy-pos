# Pharmacy Sales & Inventory Analysis using SQL

## Overview
This project focuses on analyzing pharmacy sales and inventory data
using SQL to extract meaningful business insights.

The dataset contains details about medicines, sales transactions,
categories, quantities, pricing, stock levels, and expiry dates.

## Objectives
- Analyze overall sales performance
- Identify top-selling medicines
- Understand category-wise revenue contribution
- Monitor stock levels and expiry risks

## Analysis Performed
The following SQL analyses were carried out:
- Total revenue calculation
- Daily and monthly sales trends
- Top-selling medicines by quantity
- Category-wise sales analysis
- Average order value calculation
- Identification of low-stock medicines
- Detection of expired or near-expiry medicines

## SQL Skills Used
- SELECT statements
- Aggregate functions (SUM, AVG)
- GROUP BY and ORDER BY
- Filtering with WHERE conditions
- Date-based analysis

## Tools
- SQL (MySQL syntax)
- CSV dataset
- GitHub for version control

## Purpose
This analysis was performed to demonstrate practical SQL skills
for business and data analytics use cases.
